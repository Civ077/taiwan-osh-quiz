# 題庫 API 部署清單（約 5 分鐘，做一次即可）

用 **有試算表編輯權的 Google 帳號**（wanghsiwwei 或 seyumi77 都可以）操作。

1. 開啟題庫試算表  
   https://docs.google.com/spreadsheets/d/1FuC3O7A6pC0b42tiT2F7PxBUysW3IwutPxJquaa8shg/edit
2. 選單「擴充功能 → Apps Script」。左側檔案 `程式碼.gs` 內容全部刪掉，
   把 `gas/Code.gs` 整個貼上，Ctrl+S 儲存。專案名稱改成「知識王題庫API」。
3. 右上「部署 → 新增部署作業」→ 齒輪選「網頁應用程式」：
   - 說明：v1
   - 執行身分：**我**
   - 誰可以存取：**所有人**
   → 按「部署」。第一次會要求授權：選帳號 → 進階 → 前往（不安全）→ 允許。
4. 複製「網頁應用程式網址」（結尾是 `/exec`），貼到瀏覽器加上 `?ping=1` 測試，
   看到 `{"ok":true,"version":1,...}` 就成功。
5. 把網址填進 `docs/app.js` 最上面的 `CFG.bankUrl`（或直接把網址告訴 Claude 幫你改），推上 GitHub。
6. 回到試算表重新整理，上方會多一個「知識王」選單：
   - **清除快取**：改完題目想立刻生效時按（否則最多等 5 分鐘）。
   - **檢查題庫**：列出答案不是 a–d、id 重複的列，以及各狀態題數。

## 之後改 Code.gs 時
Apps Script 編輯器貼上新版 → 儲存 → 「部署 → 管理部署作業 → 編輯（鉛筆）→ 版本：新版本 → 部署」。
網址不變。把 `GAS_VERSION` 加 1，`?ping=1` 會回新的版本號，方便確認有部署到。

## 前端怎麼讀
- 正式：`<exec>` 只回 `status = active` 的題目。
- 審題期間：`<exec>?status=all` 含 draft，前端 `CFG.useDraft = true` 時會用這個。
- Config 分頁的參數（每局題數、秒數、計分係數）會一起回傳，前端以雲端值覆蓋預設值，改參數不用改程式。
- 雲端讀不到（沒網路、尚未部署）自動退回 repo 內的 `docs/data/questions.json`。

## v2：讓 Claude 直接把題目寫進 Sheet（做一次，之後每批不用再貼）
1. Apps Script 編輯器貼上新版 `gas/Code.gs`（`GAS_VERSION = 2`，多了 `doPost`）→ 儲存 →
   「部署 → 管理部署作業 → 編輯 → 版本：新版本 → 部署」。
2. 試算表 Config 分頁新增一列：A 欄 `import_token`、B 欄填一串自訂密碼（例如 20 個隨機英數字）。
3. 把同一串密碼存成 `gas/.token`（此檔已在 .gitignore，不會上傳）。
4. 測試：`python 題庫/push_to_sheet.py ping` 應回 `"version":2`；
   之後 `python 題庫/push_to_sheet.py questions 4` 就會把批次 4 接到 Questions 最後（id 重複自動跳過）。
