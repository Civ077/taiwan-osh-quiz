# 全庫逐題複核（不抽樣）
每組一個檔（R01…R15），列出該組負責的題庫檔與題數。合計 184 檔、7,674 題。
複核項目（每一題都要做）：
1. 正確選項（依 answer 欄位，批次1–3 不一定是第一個）在所引條文下確實正確
2. 題幹與正確選項的數字、期限、百分比、門檻、機關名稱與法規原文完全一致（注意中文數字寫法：一．五／一點五／三○○／二二○）
3. 其餘三個選項在該法規下都是錯的（特別注意：施行日期題的干擾選項若寫出法規真正的發布日，就會變成兩個正確答案）
4. 英文題目與選項的意思和中文一致，數字一致
5. article 欄位就是該題實際考的條文（跨兩條可寫「第7條、第8條」）
修正原則：就地修，保持 11 欄、每語言 4 個選項、答案字母不變、四個選項長度相近；無法修正才刪除。
完成後每個改過的檔要跑 `python -c "import <檔>"` 與 `python check_options.py <檔>`（須為 0）。
不要執行 build_sheet.py、不要執行 git、不要在 題庫 目錄建立暫存檔。
